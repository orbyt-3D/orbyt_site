Models and agents

Load real models as parts, then let an AI agent build, edit and render scenes through the orbyt MCP server.

Preview. The orbyt package is in active development. This page describes the 0.9.x API it is being built to; names may still change before 1.0.

Models are parts

loadGltf() splits a GLB or glTF file into parts: one entry per mesh, each with a stable id, name, material and bounding box. Everything in orbyt, from rendering to agent tools, works on parts.

const { parts } = await loadGltf('/airport.glb');
parts.filter(p => p.name.includes('truck'));   // pick parts by name
renderer.replaceParts(parts);                       // hot-swap the model

The MCP server

orbyt-mcp exposes a live scene to any agent that speaks the Model Context Protocol over stdio. The agent edits the scene with tool calls and asks for rendered frames to check its work.

npx orbyt-mcp --backend gpu --memory 256
FlagValuesNotes
--backendgpu | cpugpu renders with WebGL2 in a headless browser; cpu uses software rendering where no GPU is available.
--memoryMiBBudget for textures and geometry inside the server.

Connect it to an MCP client

Add orbyt to your client's MCP configuration, for example:

{
  "mcpServers": {
    "orbyt": {
      "command": "npx",
      "args": ["-y", "orbyt-mcp", "--backend", "gpu", "--memory", "256"]
    }
  }
}

Tools

core tools are part of the first release; roadmap tools are planned and will land across 0.9.x.

ToolWhat it doesStatus
create_sceneStart an empty scene with a sky and ground.core
load_modelLoad a GLB/glTF file and add its parts.core
add_primitiveAdd a box, sphere, cylinder, plane or cone.core
remove_partDelete a part by id.core
list_partsList parts with ids, names, materials and bounds.core
describe_scenePlain-language summary of what is in the scene.core
set_materialChange colour, roughness, metalness, emissive or opacity.core
set_cameraMove the camera with eye, target and fov.core
set_environmentSwitch HDRI, sky colours, fog and exposure.core
render_frameRender a Flare frame and return it as a PNG.core
transform_partMove, rotate or scale a part.roadmap
set_lightAdd or edit sun, spot and point lights.roadmap
explode_viewPull parts apart along their centres to show assembly.roadmap
blend_meshesMorph between two meshes or shape keys.roadmap
bake_framePath-trace a still with Bake.roadmap
compare_viewsRender labelled views side by side for review.roadmap
render_normalsRender world-space normals for inspection.roadmap
snapshotSave and restore scene state.roadmap
export_glbExport the current scene as GLB.roadmap

A typical agent loop

  1. create_scene or load_model to get something on stage.
  2. list_parts / describe_scene to understand it.
  3. set_material, set_camera, set_environment to make changes.
  4. render_frame to look at the result, then repeat.
