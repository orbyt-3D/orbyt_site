Getting started

Install orbyt, put a model on screen with Flare, then render a path-traced still with Bake.

0.9.2 preview. The engine is built and tested; publishing to npm is coming soon, so the install line below will work once the package is live. Names may still change before 1.0.

Install

npm install orbyt@npm:@orbythq/orbyt@0.9.2

orbyt ships as ES modules with TypeScript types. It uses three under the hood, installed for you as a dependency. Any bundler works (Vite, webpack, esbuild), or load it straight from a CDN with an import map.

Your first scene

Give Flare a <canvas>, the parts of a model and a few options, then call render() with a camera.

import { Flare } from 'orbyt';
import { loadGltf } from 'orbyt/addons/gltf';
import { loadHdri } from 'orbyt/addons/hdri';

const canvas = document.querySelector('canvas');
const { parts } = await loadGltf('/server-hall.glb');
const map = await loadHdri('/dusk.hdr');

const renderer = new Flare(canvas, parts, {
  hdr: true,
  ground: false,
  environment: { map },
});

renderer.render({ eye: [42, 28, 60], target: [0, 2, -6] });

Call render() again whenever the camera or the scene changes, or every frame inside requestAnimationFrame for animation.

Flare options

OptionDefaultWhat it does
hdrtrueHalf-float pipeline: MSAA render target, bloom, then ACES tone mapping. false renders straight to the canvas (still ACES).
bloomonfalse, or { strength: 0.3, radius: 0.35, threshold: 1 }. Only HDR highlights (emissive above 1) glow by default.
samples4MSAA samples. 0 turns anti-aliasing off.
pixelRatioscreen, max 2Render resolution multiplier.
shadowstruetrue, false or a shadow-map size. The sun's shadow frustum is fitted to the scene bounds.
groundtrueShadow-receiving ground that fades into the background, or { color, roughness, y }.
environmentstudio{ map, intensity, background, blur, rotation }. map comes from loadHdri(); without one a neutral studio environment lights the scene.
background#060b10Solid background when the environment map isn't shown.
sunonKey light: false or { direction, color, intensity: 1.8 }.
exposure1Tone-mapping exposure.
preserveDrawingBufferfalseTurn on to read pixels back, e.g. canvas.toDataURL().
renderer–Reuse an existing THREE.WebGLRenderer.

Render parameters

FieldTypeNotes
eye[x, y, z]Camera position in metres.
target[x, y, z]Point the camera looks at.
fovnumberVertical field of view in degrees. Default 35.
exposurenumberTone-mapping exposure. Default 1.
timesecondsDrives animated parts such as rotors or vehicles.

Path-traced stills with Bake

Bake takes the same parts and camera and returns a converged, path-traced image: slower, with true soft shadows, reflections and global illumination.

import { Bake } from 'orbyt';

const bake = new Bake(canvas, parts, { environment: { map } });
const image = await bake.render({ eye: [42, 28, 60], target: [0, 2, -6], samples: 128 });
img.src = image.toDataURL();

render() resolves to { samples, ms, canvas, toDataURL(), toBlob() } and also accepts onProgress, an AbortSignal and timeoutMs. The first bake compiles a large shader: a few seconds on most GPUs, up to about 45 s with Direct3D 11 on Windows; later bakes start immediately.

Clean up

Call renderer.dispose() when you remove the canvas to free GPU memory. Swap models without recreating the renderer with renderer.replaceParts(parts).
